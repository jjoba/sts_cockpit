Model directory

Everything in model_objects/production. Held-out Heart-kill metrics for v21 and later, all scored on the same cleaned test set (the finetuning test file with modded runs removed, 1,266,342 rows), so they are directly comparable. Numbers for v21 and v22 differ slightly from older write-ups, which used the test set before modded runs were removed. Earlier models used a different split and have none. Precision, recall and F1 use the standard 0.5 threshold. ECE is equal-frequency-bin calibration error.

Which should I use?

Default pick: the highest version number with the best AUC, so fnn_v25_alpha_beta_mt_hp_gold_flip_synthetic. It is the recipe the experiment notes call the current base: cumulative upgrades, a flip penalty tested on synthetic decks (no card gets worse when upgraded), five heads, and HP and gold as inputs. It needs your real HP and gold, which you set on the Run page. If you don't want to track HP and gold, fnn_v25_ft_mt_flip_synthetic is the same recipe without them (and without pretraining). The differences between the top models are small (see the noise note in outstanding_experiments.md), and F1 and recall at 0.5 are low for every model because the Heart-kill rate is low.

Rule of thumb: all models are close. Pick a faster-to-load or older model only if you want a different set of card preferences; none is dramatically better on the 0-1 decision scale.
