Which should I use?

Default pick: highest version number with the best AUC, so fnn_v22_alpha_beta_mt_cum. In the real app these numbers would be read from a metrics file written next to each model, so a new model shows up and becomes the default automatically. The differences between the top models are small (see the noise note in outstanding_experiments.md), and F1 and recall at 0.5 are low for every model because the Heart-kill rate is low.

Rule of thumb: all models are close. Pick a faster-to-load or older model only if you want a different set of card preferences; none is dramatically better on the 0-1 decision scale.
